# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I created my own Linux user account, explored the Linux environment, gathered system information, organized files and directories, and created a Cloud Computing portfolio using GitHub.

## Objectives

The objectives of this laboratory were to:

* Access a cloud-based Linux environment using KillerCoda.
* Navigate the Linux operating system.
* Gather basic system information.
* Create and organize files and directories using Linux commands.
* Create a professional GitHub repository.
* Document technical activities using Markdown.

## Activities Performed

1. Launched an Ubuntu Linux Playground using KillerCoda.
2. Verified that the Linux terminal was working.
3. Created the Linux user `rcontawe`.
4. Added `rcontawe` to the sudo group.
5. Logged in using the new user account.
6. Checked the username, working directory, and hostname.
7. Collected Linux system information.
8. Created folders and Markdown files.
9. Created the `CCM101-rcontawe` GitHub repository.
10. Organized the laboratory files and screenshots.


## Skills Learned

Through this laboratory, I learned how to work with a cloud-based Linux environment, create and manage Linux users, navigate directories, collect system information, create files, use Markdown, and organize a professional GitHub repository.

I also learned the importance of documenting technical work and keeping laboratory activities organized using GitHub.
